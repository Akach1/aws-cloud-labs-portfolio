# AWS Cloud Portfolio Project Summary

## Overview

This portfolio documents twelve AWS cloud engineering projects completed through the AWS SimuLearn Cloud Practitioner learning path.

The projects demonstrate hands-on experience with cloud infrastructure, networking, storage, databases, security, scalability, monitoring, cost optimization, and high-availability architectures.

---

# Featured Projects

These projects best demonstrate cloud engineering and cloud operations skills:

### Networking Concepts

Designed a secure network architecture using Amazon VPC, public and private subnets, route tables, internet gateways, and security groups.

Skills:
- Amazon VPC
- Networking
- Security Groups
- Route Tables

---

### Core Security Concepts

Implemented least-privilege access using AWS IAM groups, users, and managed policies.

Skills:
- IAM
- Access Control
- Cloud Security

---

### Databases in Practice

Configured highly available Amazon RDS environments using Multi-AZ deployments and read replicas.

Skills:
- Amazon RDS
- High Availability
- Database Administration

---

### Highly Available Web Applications

Designed a resilient web application architecture using Route 53, CloudFront, Elastic Load Balancing, Auto Scaling, and Amazon RDS.

Skills:
- High Availability
- Route 53
- CloudFront
- Auto Scaling
