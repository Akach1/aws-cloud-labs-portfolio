## Architecture Summary

This solution improves website reliability by migrating static web content to Amazon S3 static website hosting. Users access the website through a web portal, which retrieves content directly from an S3 bucket configured for public website hosting.

Bucket policies are used to control access to website resources while Amazon S3 provides highly durable and scalable storage for static content.

## Key Components

| Component | Purpose |
|------------|----------|
| Amazon S3 | Hosts website files |
| Static Website Hosting | Serves web content |
| Bucket Policy | Controls access permissions |
| Web Portal | Provides user access |
| Website Content | HTML, CSS, and static assets |
