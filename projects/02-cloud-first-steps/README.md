# Cloud First Steps

## Business Scenario

The island stabilization team needed to increase the reliability and availability of its stabilization system.

## Business Requirements

- Improve system availability
- Reduce infrastructure failures
- Increase service reliability

## Proposed AWS Solution

Deploy compute resources within AWS using resilient infrastructure across Availability Zones.

## AWS Services Used

- Amazon EC2
- Amazon EBS
- AWS Availability Zones

## Implementation

- Deployed EC2 instances
- Worked with Amazon EBS storage
- Explored Availability Zones
- Configured cloud infrastructure components

## Security Considerations

- Followed AWS infrastructure security best practices
- Evaluated secure deployment approaches

## Business Outcome

Increased service resiliency and improved infrastructure availability.

## Skills Demonstrated

- EC2 Administration
- Cloud Infrastructure
- Storage Management
- Availability Design

## Key Learnings

- EC2 instance management
- EBS storage usage
- Availability Zone concepts
- Infrastructure deployment

## Resume Bullet

Deployed AWS cloud infrastructure using EC2 and EBS while implementing availability-focused design principles.
