# Computing Solutions

## Business Scenario

A school wanted to upgrade its scheduling application by increasing compute and memory resources.

## Business Requirements

- Improve application performance
- Increase available compute capacity
- Increase memory resources

## Proposed AWS Solution

Resize and optimize EC2 infrastructure to meet new workload requirements.

## AWS Services Used

- Amazon EC2

## Implementation

- Evaluated infrastructure requirements
- Selected appropriate EC2 resources
- Modified compute configurations
- Validated application performance

## Security Considerations

- Maintained access controls during infrastructure updates

## Business Outcome

Improved application performance and resource utilization.

## Skills Demonstrated

- EC2 Management
- Infrastructure Optimization
- Cloud Operations

## Key Learnings

- Instance sizing
- Compute optimization
- Resource planning

## Resume Bullet

Optimized cloud infrastructure by evaluating workload requirements and implementing improved EC2 resource configurations.
