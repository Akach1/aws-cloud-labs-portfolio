# First NoSQL Database

## Business Scenario

A streaming company needed a scalable database solution to store large volumes of viewer behavior data.

## Business Requirements

- Support large data volumes
- Scale automatically
- Improve performance

## Proposed AWS Solution

Implement a NoSQL database architecture capable of handling rapidly growing workloads.

## AWS Services Used

## Architecture Summary

This solution uses Amazon DynamoDB to store and process viewer behavior data generated by streaming applications. DynamoDB provides a scalable NoSQL database architecture capable of handling large volumes of application data without traditional database administration.

## Key Components

| Component | Purpose |
|------------|----------|
| Amazon DynamoDB | Stores viewer behavior data |
| DynamoDB Table | Holds application records |
| Fire TV Application | Generates usage events |
| Users | Generate viewing activity |
| Developer | Queries and manages data |
